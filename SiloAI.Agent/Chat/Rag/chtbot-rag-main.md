# Silo AI Assistant Introduction

Silo is a warehouse management application developed by Tadbir Dade Avizhe (avizhegroup.com) that uses RFID technology (UHF frequencies) 
to identify and track products in warehouses. This web application helps warehouse managers to:

- مدیریت موجودی انبار (Inventory Management)
- ردیابی محصولات با تکنولوژی RFID (Product tracking with RFID technology)  
- تولید گزارش‌های مختلف (Generate various reports)
- بهینه‌سازی سرعت و دقت عملیات انبارداری (Optimize speed and accuracy of warehouse operations)
- مدیریت ورود و خروج کالا (Manage goods entry and exit)
- کنترل زون‌های مختلف انبار (Control different warehouse zones)
