# ثبت تردد Page Overview

## Purpose
- ثبت تردد page is available from the menu:حراست ← ثبت تردد 
- This page is used to register and display traffic information related to trucks and goods entering and leaving the facility.
Truck traffic registration is performed in three main stages: پذیرش، ورود و خروج.

## Truck Traffic Registration Stages

### Admission
This stage is used to record initial information and includes three sections:
- اطلاعات شخص
- اطلاعات ماشین
- اطلاعات پذیرش

### Entry
- This stage contains only one section for recording truck entry information into the facility.

### Exit
The exit stage is used to complete truck traffic records and includes:
- توضیحات خروج
- شناسایی کالا از طریق گیت
- کرایه حمل
- کاربر ثبت‌کننده خروج

The page also displays a list of trucks that have not yet exited the facility, allowing easy tracking of open truck traffic records.

## Supporting Forms for the Truck Traffic Registration Page
To manage and extend the Truck Traffic Registration page, there are two separate forms available.
- تعریف فیلدهای اطلاعاتی
- اطلاعات پایه

## 1. Information Fields Definition
Menu path:اطلاع‌رسانی ← تعریف فیلدهای اطلاعاتی
This section allows users to add dynamic and customizable fields to the Truck Traffic Registration page based on operational needs.
For each field, the following information is defined:
1. شناسه:Automatically generated by the system
2. عنوان:The name of the field to be added
3. نوع عملیات:Specifies the operational process related to the field
Examples of نوع عملیات:
- ارسال کالا از تولید به انبار محصول
- ارسال کالا برای بارگیری
- برگشت کالا به انبار محصول
- برگشت کالا از فروش
- ارسال کالا از خط تولید به انبار تولید
- جابجایی کالا داخل انبارهای تولید، محصول یا فروش
- ارسال کالا برای خدمات پشتیبانی
- ارسال کالا به نمایشگاه، امانی، نمونه یا هدایا
- دریافت کالا در واحد خدمات
- ارسال کالا به فروش
4. The **نوع** section defines which data category the field belongs to, such as:
- اطلاعات داینامیک هدر سند
- اطلاعات داینامیک اقلام سند
- اطلاعات اقلام کالا
- اطلاعات عملیات
- اطلاعات پذیرش تردد
- اطلاعات ورود تردد
- اطلاعات خروج تردد
Related Titles are used when searching for a concept that may appear under different names in documents but refers to the same item.
5. المان سیستمی: A system element is information that is automatically generated and managed by the system, and does not require user input or modification.
Examples include Product Code or Document Number, which are used only for identification and data organization.
6. کلید سند:The Document Key option specifies whether a field is considered the primary identifier of the document.
7. Field Display Type (نوع مقدار):
Each field can have a display type that determines how it appears in the user interface:
- TextBox: Simple text input
- DropDown: Dropdown list
- Numeric: Numeric input field
- RichTextEditor: Text editor with formatting tools
**Important Note for DropDown Fields**
When DropDown is selected:
List items can be added manually
Each item is entered with a title and added using the “+” button
The Default Value section allows previewing the selected result
8. عنوان دسته: The Category Title determines which section of the Truck Registration page the field will be placed in, based on the selected type.
This means the field can be assigned to sections such as:
- اطلاعات راننده
- اطلاعات ماشین
- اطلاعات پذیرش
- اطلاعات ورود
- اطلاعات خروج
9. ترتیب نمایش:In the Display Order section, by entering a numeric value, you can define where and in what order the field will appear on the page.
Lower numbers indicate earlier display on the page.

### 1.1 Saving, Editing, and Deleting Fields
After entering the field information, click the Save button to add the field to the system.
Once saved, the field can be edited (Update) or deleted (Delete) if needed.

### 1.2 Viewing the List of Added Fields
The gray button with the three-line icon is used to display the list of all added fields.
By selecting a field from this list:
- The complete field information can be viewed
- The field can be edited or deleted if required

### 1.3 Adding Custom Fields
In the Information Fields Definition section, 
you can add any number of fields based on your operational needs to capture different types of information.

### 1.4 Displaying Fields on the Truck Registration Page
The fields you define are displayed on the Truck Registration page according to the selected:
- نوع 
- عنوان دسته 
- نوع مقدار انتخاب‌شده
Example:
A field titled “شرح ماشین” with:
Type: اطلاعات پذیرش تردد
Category Title: اطلاعات ماشین
will be displayed on the Truck Registration page under the پذیرش stage, in the اطلاعات ماشین tab.
If the selected value type is TextBox, the field will appear as a simple text input box on the page.

## 2.Basic Information Form for the Truck Registration Page
Alongside the Truck Registration page, there is a form called اطلاعات پایه.
This form allows you to define core data and selectable lists for certain fields used in truck registration.
These values appear in the Truck Registration page as predefined options for selection.
1.نوع ماشین:
In this section, you can define the types and models of trucks that move within the facility, 
such as: سواری، وانت، خاور، کامیون, etc.
To add a truck type:
- Enter the truck type name in the Title field
- Click the Save butto
After saving, the truck type is added to the Truck Registration page.
You can also delete a truck type by selecting it from the list in the Truck Type section of the Basic Information form.
2. شرکت:
In the Company section, you can add companies to which products will be sent or with which you collaborate.
These companies will later be selectable in the Truck Registration page.
3. فرستنده / گیرنده:
This section is used to define and manage sender or receiver information for the goods.
4. نوع عملیات:
In the نوع عملیات section, you can define the type of operation and also the reason for the visit.
Examples of نوع عملیات:
- ارسال کالا
- خرید خارجی
- جابجایی کالا بین انبارها
- خروج ضایعات
Examples of علت مراجعه:
- ارسال کالا
- (تحویل کالا (خرید داخلی
- (تحویل کالا (خرید خارجی
- (تحویل کالا (خرید خدمات
Visit reasons are first defined in a separate section and then selected via a dropdown in the Operation Type field.
5. مقصد عملیات:
In this section, you can specify the destination related to the selected operation.
6. باربری:
In the Carrier section, you can add transport companies you work with or have contracts with.
These carriers become selectable in the Truck Registration page.
7. نوع کالا:
Here, you can define the type of product or goods, for example: waste, finished product, or other categories.
8. محل مراجعه:
In the Visit Location section, you can specify the location or unit being visited.

### 2.1 Placement of Basic Information Fields in the Truck Registration Page
All fields defined in the اطلاعات پایه section are displayed in different sections and tabs of the Truck Registration page.
1. پذیرش Section
- طلاعات شخص Tab: شرکت field
- اطلاعات ماشین Tab: نوع ماشین field
- اطلاعات پذیرش Tab: علت مراجعه، باربری، فرستنده/گیرنده، نوع عملیات، مقصد عملیات fields
2. ورود Section
- محل مراجعه field
Note: All these fields are populated from the Basic Information page and are available for selection directly
in the Truck Registration page.

## Truck Registration
At the top of the Truck Registration page, there is a section called شناسه which is non-editable.
Next to it, the following fields are available for entering driver information and are editable:
- کد ملی 
- نام راننده
- شماره تلفن
- پلاک
Users can edit these fields or, by entering the data and clicking the Search button,
view the driver’s full information in the lower section of the page.
**Main Sections of Truck Registration**
- The page consists of three main sections:پذیرش، ورود ، خروج.

### پذیرش Section in the Truck Registration Page
**Person Information Tab**
This tab contains several fixed fields:
- کد ملی راننده
- نام راننده
- نام خانوادگی راننده
- شماره تلفن راننده
- شرکت
**اطلاعات ماشین Tab**
- License پلاک field, which must be entered in the correct format.
- نوع ماشین
**اطلاعات پذیرش Tab**
This tab includes the following:
- Notes / Description
- نوبت پذیرش:The queue number can be entered manually
Or, by clicking the blue button, the queue is assigned automatically based on previously registered admissions and the waiting list
- Photo Upload:Next to the queue button, there is an option to upload a photo
Uploaded photos are added to the Document Gallery
By right-clicking the photo, the National ID and License Plate text can be extracted from the image
Uploaded photos can also be deleted or downloaded
Clicking the green button uploads the selected photo
- Registration Information:
In a dedicated box, you can view کاربر ثبت مراجعه، تاریخ پذیرش و ساعت پذیرش
- فرستنده / گیرنده 
-  مقصد عملیات 
- باربری 
-  نوع عملیات 
- علت مراجعه 

### ورود Section in the Truck Registration Page
The ورود section contains a single tab called ورود.
**Contents of the Entry Tab**
1.وزن ورود Field:
- The weight is measured in tons
- It can be entered manually
- Or, if the system is connected to a weighing scale,
clicking the button next to the field will automatically import the weight from the scale into the program
2.افزودن کالا Field:
- Clicking this field opens a window
- In the window, you can enter نوع کالا، مقدار، واحد کالا ، شرح کالا
- After entering the details, click the + button to add the product to the list
3.Entry Registration Information:
- In this section, you can view the username, entry date, and entry time.

### خروج Section in the Truck Registration Page
The خروج section includes four main parts:
- توضیحات خروج
- شناسایی کالا از طریق گیت
- کرایه حمل
- کاربر ثبت خروج
1. توضیحات خروج Tab:
This part includes the following fields:
- Exit Weight: measured in tons; can be entered manually or automatically via the connected weighing scale
- Net Cargo Weight
- Add Product:
Clicking this option opens a window
In the window, you can enter product type, quantity, unit, and description
Click the + button to add the product to the list
2. شناسایی کالا از طریق گیت Tab:
- This tab is related to products inside the warehouse and does not display all products
- Only products that have a registered quantity for exit and existing data are shown (e.g., products sent for sales)
- To identify a product:
- Select the identification station
- Click the green button to navigate to the related page
- After returning to this tab and clicking the blue button, the list of products in the process of exiting will be displayed
3. کرایه حمل Tab:
This tab includes the following fields:
- نوع پرداخت:specify whether the payment is handled by the receiver, sender, or company
- محاسبه کرایه حمل:The freight cost is calculated automatically based on a formula defined externally by each company.
The system does not define, display, explain, or assume any specific calculation logic.
Only the final calculated values are shown to the user.
- قیمت واحد
- مبلغ نهایی کرایه
- مسافت:the distance traveled for product delivery is taken into account
4. کاربر ثبت خروج Tab
- Displays the username of the person who registered the exit

### Adding Custom Fields
- In all sections, you can add custom fields (e.g., شماره گواهینامه, توضیحات ورود, شماره تماس صاحب بار, or any other field) with the desired layout using the Information Fields Definition
- After entering the information, it can be saved or printed

### List of Trucks That Haven’t Exited
- This list shows the نوبت پذیرش راننده‌ها، علت مراجعه و وضعیت فعلی
- Trucks remain in this list until their exit is registered
- Click the Refresh button below the table to update the list

## Summary
The Truck Registration page is designed to register and manage trucks and goods entering and exiting the facility.
The page is divided into three main sections:
- Admission: register driver, vehicle, and admission details, assign queue, and upload documents
- Entry: record entry weight and incoming products
- Exit: record exit weight, outgoing products, transportation fee, and the user who registered the exit
All selectable and registrable information is loaded from the Basic Information page, and custom fields can also be added.
Additionally, a list of trucks that haven’t exited is displayed to track their status and queue until their exit is registered.
